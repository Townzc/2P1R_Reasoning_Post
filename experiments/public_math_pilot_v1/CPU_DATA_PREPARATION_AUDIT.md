# Public-Math pilot: CPU data preparation

The immutable release contains 4,096 unique training questions, 512 development questions, and 20,000 future training-pool IDs. No pretrained model forward, GPU update, QDW annotation, or generation was executed by this preparation. The ready engineering profiles were not run.

Release manifest SHA256: `f7c67a1c523c3ec5dfbd1ae63506a9ce91dd03683643dcf3b7a72c70b16fa370`. Preflight input SHA256: `06660ef5f0a12dde2118b3f7d436a7c0f3f34f492632ec13e438523b33d50c8c`.

All 859,494 Numina train questions were indexed. Exact matching produced 814,345 distinct Numina question identities. Fixed128-permutation MinHash retrieved 989,909 candidate pairs; exact length/Jaccard checks accepted 62,060 edges. Components connected to MATH500, complete MATH test5,000, GSM8K test1,319, or Minerva272 removed 503 original rows. Retrieval is approximate and does not establish exhaustive semantic deduplication. Minerva answers were not projected or published.

The selector checked an ordered prefix of 20,949 unexcluded groups. Within each group, the first eligible original row ID supplied the unchanged reference. Later unseen groups cannot precede the selected dev/train prefixes, so this yields the same requested prefixes as exhaustive eligibility filtering; the total globally eligible pool remains unknown. Dev additionally requires a nonempty answer from the frozen Qwen reference parser. No mask-success or model-correctness filter was used.

The final pilot has 1,800,417 supervised response tokens including one assistant end per row, and maximum complete input length 1969. All4,096 encoded hashes, prompt labels, identical full/blank response IDs, and ending contracts were checked; no reference was truncated. Dev and future-pool groups are disjoint, and pilot is the first4,096 future-pool IDs. All official generation questions fit the4,096 context with2,048 output-token reservation.

Three earlier preparation candidates are preserved, with reasons and available hashes in `release_v1/PREPARATION_ATTEMPTS.json`. Initial literal image tags missed ordinary diagram references. The final rule conservatively excludes explicit external visual citations and applies three canonical-question-SHA adjudications for missing shaded boundaries. Independent question-only context review covered55 broad visual-trigger cases in the preceding pilot/dev candidate, not all20,000 future questions. The technical rules apply throughout the scanned eligibility prefix. Generic mathematical images/figures, picture books, actual displayed tables, and fully specified shaded regions are retained; tests cover the two reviewed shaded-region counterexamples. Implicit visual dependencies and imperfect reference reasoning may remain. No semantic-completeness guarantee is made.

All500 MATH500 rows remain present. One upstream normalization boundary persists: `math500-test-0097`, raw answer `\text{east}`, normalizes to the empty string. It is marked `unresolved_reference`, with correctness null; it is not dropped or converted into an error. The data can be frozen, while complete benchmark scoring remains blocked by this known unresolved reference.

Twenty-eight targeted CPU tests passed (16 loss/selection,12 data), including true autograd, whole-update denominators, causal token shift, detached weights, EOS, selection ties, and unequal microbatch equivalence. These tests and the prepared stress profiles do not constitute a GPU preflight pass. `CPU_DATA_PREPARATION_AUDIT.json` records the exact scope, dependencies, hashes, exclusions and limits.
