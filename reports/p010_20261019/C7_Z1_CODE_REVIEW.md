Scope: Claude commit1916613325dc669a030cd290df3e276d815e6680, `audit/claude/20261019b/z1_secondary.py` and `z1_stats.py`. The two source hashes and read receipt are in C7_SOURCE_BINDING.json. This is a code review, not a re-annotation or an independent rerun of real Z1 scores. Four synthetic pure-function counterexamples were executed once; no Z1 labels were loaded or changed.

1. **P1 — the generated annotation input does not implement blinding.** secondary lines239–247 write `model`, identifying `stratum`, `strict`, `secondary`, `cand` and `rule` into the only item artifact. Shuffling does not hide these fields, and A/B strata themselves reveal the model. Generate a separate blinded, opaque-ID annotation artifact before labels, keep the mapping separately, and disclose that the existing annotation pass cannot be made prospectively blind after the fact. Owner spot-check is separately blinded; it does not establish that the Claude pass was blind.
2. **P1 — weighted A-only parser misses are not the net gap explained.** stats lines13–26 weight only A(base wrong/student right); B and C are descriptive counts. Labeling `popA*pPM/gap` as the fraction of the entire gap explained omits B's subtraction and C's paired base/student contributions. Either label this strictly as A-stratum base misses divided by the observed gap, or calculate the signed stratified estimand with paired C contributions and a corresponding uncertainty interval. Zero sampled student misses cannot establish zero population misses. This review makes no new numeric estimate.
3. **P1 — box extraction can disagree with the reused symbolic verdict.** secondary `last_boxed` chooses the last boxed occurrence in preference to any fbox, even a later fbox; it does not match the frozen scorer's joint last-box rule or escaped-brace handling. `cut_leak` also changes the text before extraction, while load_math lines181–184 copies the original symbolic verdict for any detected box without checking that the extracted answer is the identical frozen candidate. Only reuse the original symbolic verdict when the extraction identity matches; otherwise apply a source-bound secondary comparison and preserve the old label. Example `boxed{1} ... fbox{2}` extracts1.
4. **P2 — numeric marker extraction silently changes fractions/equations.** `gsm_candidate` takes the first regex number after a marker. `The answer is 1/2.` yields1; `The answer is 2 + 3 = 5.` yields2. The rational handling in `to_num` is bypassed. Extract a complete final answer expression with an explicit ambiguity policy. The catch-all last-line rule and `Note:` truncation can return an intermediate value; `Intermediate boxed{1}.\nNote: correction; final answer is2` returns1. Gold-independent extraction is a useful property but does not prove final-answer precision.
5. **P2 — snapshot/source identity and frozen plan scope need explicit binding.** load_gsm consumes P009 P0 (650/950), whereas planv3 §3.8 names original638/969. The report discloses this difference, but that is a changed pair, not a byte-identical implementation of the named pair. Supply a scoped amendment or the intended source. Both loaders currently lack expected manifest hashes, exact row counts and ID-set equality checks; malformed/mixed bundles can be partially summarized without an integrity error.
6. **P2 — output immutability/annotation schema.** `exist_ok=True` plus mode'w' overwrites outputs on repeat. Duplicate labels silently collapse in a dict; unknown labels and exact label-ID coverage are not checked. The taxonomy omits the planned “coincidental correctness” class; only strict-wrong outputs are selected, so lucky strict-correct answers are outside this design. State that restriction. Sample counts are40question pairs/task but48outputs/task (96total), not80outputs; clarify the unit.
