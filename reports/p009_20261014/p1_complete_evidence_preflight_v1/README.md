# Complete P1 evidence publisher — prepared, not executed

This stand-alone standard-library tool reads the one-pass completed local journal
and verifies original hashes, contiguous row/chunk order, once-only pair/cache
history, real driver/numeric reviews and all complete denominator/exclusion
records. It never imports a scoring pool, calls math-verify, decodes raw tokens,
loads a model, or changes labels. Existing Boolean outcomes are summed only after
the entire frozen roster completes; no prefix score is used for admission.

It preserves all failed/timed-out original pair outcomes, fixed50 disagreement
samples and >2% fallback samples up to25 per pool, plus >0.5% unique-pair outer
flags. Sample adjudications remain null and eligibility/G0 remain false pending
real independent inspection. The original boxed denominator is copied, explicitly
not independently reparsed by this publisher. It does not substitute for A2.

Publication is create-only, and a partial output blocks a whole-tool rerun.
A complete archive is read back against every file SHA. The only projected field
is timing_review.local_report_path in remaining chunk intents; all original SHAs
and exact projection mappings are disclosed. Original completion proofs continue
to bind private original intent bytes, not the public projection. No personal
host locator is sent publicly, and no claim of independently reading private
originals is made. All other original evidence and the source are included.

Nine new synthetic saved-proof checks passed once. They test cache reuse, failed
or missing chunk proofs, mutated prefix input, duplicate attempts, non-Boolean
labels, incomplete final rows, changed numeric review and privacy projection.
They are not real scoring, a full live archive, or an independently audited P1.
All twelve accepted scoring sources remain unchanged. Remaining scoring is still
waiting for its separate actual-first100 numeric review; this publisher's code
review does not block that independent invocation.
