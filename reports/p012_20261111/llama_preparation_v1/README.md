# Llama Tier 1 and C7 preparation

Twenty main-training requests and fourteen C7 requests use the accepted C6/C7 inputs, official pinned Llama1B weights and unchanged shared code. Every main dose and full-template token count is validated; all C7 generation configs come directly from the reviewed frozen manifest. Built with Llama.

The first admitted batch is Llama base × MATH (five cells, seed17, full greedy evaluations reserved) plus four NLL measurements. The remaining requests are prepared and unadmitted. `FIRST_ADMISSION.json` contains actual balances, completed-run accounting and per-run buffered forecasts. No additional main-grid recipe or evaluation path was introduced.
