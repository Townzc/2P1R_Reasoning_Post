- LC-4（Base 的长 − 短 ≥ +5pp）：成立，+17.5 [+16.3, +18.7]。
- 长解臂比 Base 自己的训练前基线高 16.0pp [+12.4, +20.0]（MATH-500）；短解臂与训练前基线持平（−0.8 [−4.6, +3.0]）。
- 长解臂的截断率是短解臂的两倍（452 条，其中只有 7 条被判为循环）。只看正常终止的题，长解臂是 96.3%。

**这对上一轮的混杂意味着什么。** 上一轮的问题是：9B 的长解臂学的是它自己的输出，"长"和"是自己的分布"分不开。这里学生是 9B-Base，解答是另一个模型（9B）写的，Base 训练前只有 71%。它学了 128 步之后到了 87%，说明长解答对"不是作者"的模型同样有效。

限制要写清楚：

- 9B 和 9B-Base 是同一族的模型，前者很可能就是从后者调出来的，所以这还不是一个"来源完全无关"的检验。已排定的"9B 学 4B 的长解答"是另一个角度。
- 长度之外，两份解答的内容和细致程度也不同，这组对照分不开"长"和"写得细"。
- 两臂的监督 token 数是 766,734 对 302,694。
- 一个种子。

## 3. 我上一轮的一处推断需要收回

`46694f51` §5 里我写了：长解臂末段的训练 loss 只有 0.019，"模型在学自己本来就会写的东西，参数几乎不用动"。

这里 Base 长解臂的末段 loss 同样很低（0.025），而它的行为变化很大（+16pp）。所以低 loss 反映的是这类长解答逐 token 很好预测，不能据此推断模型没怎么变。长、短两臂的每 token loss 也不能互相比较。那句推断收回；"掉分来自训练解答本身，不是微调这个操作"这个结论不受影响。
