# Per-call quiescence for the original concurrent owner jobs

The six-call shared Modal app may remain running after an individual original call finishes. Waiting for whole-app STOPPED0 would delay a completed baseline past its own closeout window. The new adapter checks the original FunctionCall graph root identity, every node SUCCESS, its real task IDs absent from the current container list, and the exact completed local/remote receipt and claim. It explicitly does not claim the whole app stopped, and records the other app containers. Unknown provider shape, wrong call/function, pending/failing children or an active owned container are rejected. The provider proof is named PROVIDER_CALL_QUIESCENT, never falsely labeled whole-app STOPPED0.

Original collection bytes, complete state/trajectory/raw oracle, scorer and absolute result cutoff unchanged. New producer hash bound in its ATTEMPT. Original seven source63/model specs are untouched; this addendum is local transport only. Four new tests passed once; a fifth new unknown-container-schema test passed separately after that guard was added. No model, collector or science run by this preparation. First source inspection of a Typer command via inspect.getsource failed read-only; the installed module source and public FunctionCall API were then inspected, no provider side effects.
