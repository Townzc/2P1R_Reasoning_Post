# Closest-work audit

Verified 2026-09-11 against primary papers and the author repository identified below. This is a focused comparison, not an exhaustive novelty certification. Paper-reported findings, source-code observations and our implications are separated. No author code was executed.

## Direct overlap: questions versus answers, including MathQA

**Paper evidence (Sections 2, 4.1, 4.3 and Appendix E).** The shortest-path study uses an eight-layer/eight-head LLaMA-style model, random-walk pretraining, then shortest-path SFT. On a 2,000-node training map, five record budgets (5/10/20/60/80%) trade unique start–end questions against distinct valid paths. Insufficient path multiplicity causes redistribution without repetition; it is not a guaranteed-K design. Transfer averages three disjoint maps within training lengths. Its MathQA extension fine-tunes Qwen2.5-7B-Instruct using DeepSeek-R1 traces: approximately 1,000 training examples for gain/physics and 200 for probability, with one versus ten solutions per question. High-coverage and high-diversity question arms distinguish operation-multiset coverage from within-multiset program variation. Reported accuracy, probability/gain/physics: high coverage .792/.82/.77; high diversity .792/.74/.74; more solutions .771/.72/.70. These are record-budget comparisons, not demonstrated equality of supervised tokens or measured acquisition expense. [Paper v1](https://arxiv.org/html/2604.15306v1).

**Author-code evidence.** The full, non-truncated repository tree at commit `838c28e48b8a2cc9278263a730f0aa3c7d765a4e` contains no MathQA-named path; the inspected README and experiment dispatch describe navigation. The released sampler knows each question's available-path capacity, redistributes unused allocation and can replace a selected question with an unused question of greatest known capacity. This is an inventory-informed allocator. The SFT entry point uses a one-pass step count, batch-size default 64, seed default 42 and `reveal` as its default path representation. Defaults are not proof of every paper run. [Sampler](https://github.com/privacytrustlab/PathGeneralization/blob/838c28e48b8a2cc9278263a730f0aa3c7d765a4e/data_generation/spatial_length/split_shortest_path_qa.py), [SFT source](https://github.com/privacytrustlab/PathGeneralization/blob/838c28e48b8a2cc9278263a730f0aa3c7d765a4e/src/sft.py), [repository](https://github.com/privacytrustlab/PathGeneralization/tree/838c28e48b8a2cc9278263a730f0aa3c7d765a4e).

**Reproduction gaps, not allegations.** We did not locate a MathQA generation/filtering manifest, exact selected IDs, SFT configuration, seed-wise outcomes or attempt-level costs in this inspected release. Appendix E alone does not resolve them. The public navigation defaults do not fill those gaps. The missing evidence does not imply that the authors performed no filtering or no robustness checks. Any later reproduction must identify the relevant artifact before claiming implementation equivalence.

**Implication for this project.** “More questions versus more answers” and “coverage matters” are already directly studied in controlled and natural-language settings. Even variable realized K is not new. The remaining candidate concerns a different decision environment: available solution capacity is initially unknown, every failed query consumes resources, and a rule must commit before seeing the new pool. Whether those constraints change a useful recommendation remains to be measured. The public-code fallback is an inventory comparator, not a fair online policy with unknown outcomes.

## Contribution candidates after this comparison

1. **Measured limits of an allocation recommendation (primary).** Demonstrate, or bound the absence of, an independently reproduced change induced by the deployed acquisition process. It needs source-matched costs, a fixed information contract and prospective validation, not retrospective repricing alone.
2. **Selection-induced recommendation error (secondary).** Quantify how discarding zero-yield/incomplete-K parents changes the population and the recommended allocation. Denominator changes are descriptive; a downstream selection-effect claim needs a separately controlled comparison.
3. **Semantic explanation (conditional).** Determine whether additional verified solutions introduce distinct operations/strategies that predict marginal value beyond repeats. A blinded, reliable annotation scheme and a targeted intervention are necessary. This is not part of the minimum claim.

None is currently established. Broader active-data-selection, rejection-sampling and synthetic-data allocation literature must receive a final novelty audit before asserting priority. The present task deliberately selects a falsifiable empirical boundary, not a new optimizer, universal scaling law or optimal online acquisition algorithm.
