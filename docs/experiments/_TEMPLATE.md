# ID — Short question

**Work date:** YYYY-MM-DD UTC. **Status:** proposal / prepared / authorized-pending /
running / completed / failed / invalidated / post-hoc analysis.
**Hypothesis timing:** before outcomes / retrospectively reconstructed / post hoc.

## Question and motivation

What uncertainty justifies this attempt? Link the preceding evidence or decision.

## Competing explanations and falsifiable expectation

State the prediction and an outcome that would weaken it. Separate engineering
feasibility from scientific effects; do not claim hidden mechanisms from an endpoint.

## Design and controls

Name the intervention, comparison, common data/model/dose, primary endpoint,
secondary diagnostics, seed scheme and stopping rule. Link frozen configs instead
of duplicating every setting. For a proposal, mark unfinished specifications.

## Evidence and result

Link exact run/config/data/report paths. Record failed checks and missing data.
Use **pending** until verified results exist. Include charged runtime and source
provenance through the receipts; never invent estimates as measured results.

## Interpretation and next decision

Explain what the result supports, its limitations and the next decision it changes.
Record publication and independent artifact recovery when applicable.
