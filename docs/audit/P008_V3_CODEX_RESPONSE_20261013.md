## 3. 建议直接并入v3.1的少数条款

### F1：定义独立采购单位，固定训练seed

建议D1/D2都用相同的预定学生seed17，所有主比较和桥接共享该seed；teacher/order分别有draw专属独立随机流。若D1和D2又换训练seed，其差异同时含采购和训练变化，不能只叫采购方差。固定seed不意味着消除所有硬件/训练随机性，也不能推到任意训练seed。无需为此加新学生。

稳定种子使用带域标签/无歧义字段编码的SHA-256，再映射到后端合法范围，记录完整映射和碰撞检查。不要通过字符串无分隔拼接或依赖生成调度顺序保证流身份。按需缓存以(draw,problem,attempt)为键；缓存已存在不等于策略可免费消费。

### F2：把桥接写成条件效应及交互，不承诺唯一的贡献分解

D1/p0中，记策略差Δ(B,T)=acc(depth)−acc(breadth)。完整桥接可以报告：固定T时增加B的变化、固定B时增加T的变化，以及

`J = Δ(8,8) − Δ(8,1) − Δ(1,8) + Δ(1,1)`。

若J非零，“多少归功于数据、多少归功于训练”取决于先改变哪个因素，不能强行唯一分账。桥接只覆盖D1/p0，不证明高题价或D2有同样机制。主比较仍报告逐draw Δ_p(B)、C_p和I(B)。如果强调价格交互是否随预算变化，可预先另报`I(8)−I(1)`，标为探索，不事后挑最显著的对比。

T还需明确监督targets与更新数、完整回答整数可行性和LR规则。建议同T使用同更新数/同LR向量；U0=256、T0=524287作为拟定基准，8×对应2048updates/4194296targets。任何共同整数剂量容差须在学生结果前预定，全部输入计划一起通过。高T的优化路径是该训练资源契约的一部分，不能叫只改变答案数量。
