### 需要带上的一点：4B 的 GSM8K 0-shot 基线是只答不写的产物

4B 在 OMI-2 的 0-shot 提示词下，1,319 题里有 543 题（41.2%）直接输出一个 `\boxed{}`，不写推理。这部分的准确率是 29.7%；写了推理的 776 题是 91.1%，与 4-shot 的 92.2% 相当。所以 65.81% 反映的是输出形式，不是能力。

- 这与此前 Llama-Instruct × GSM8K 的 0-shot（4.8%）是同一类问题。
- 4B × GSM8K 的训练前参照应取 4-shot。G3 的预测本来就取两者中较高的，不受影响。
- 9B 的 0-shot 没有这个现象（0 题只答不写）。

## 4. 4B GSM8K pass@8：接受评分

**处置：接受现有 4,000 条输出，按已审过的原路径评分；不重跑，不替换。**

依据（我只看了种子、token 序列和长度，没有看答案对错）：

| 检查 | 结果 |
|---|---|
| 采样种子 | 4,000 个各不相同，全部符合 `seed + 题号 × 8 + 次数` |
| 调用 | 4,000 个不同的序列号，每条是一次独立调用 |
| 重复出现在哪里 | 274 组重复的输出，长度中位数 7 个 token，九成不超过 9 个 token |
| 输出长度 | 4,000 条里 40.5% 不超过 12 个 token，即只有一个 `\boxed{}` |
| 12 道八条全同的题 | 输出都是 6–9 个 token 的 `\boxed{…}` |
| 互不相同数与长度 | 八条全同的题平均 7 个 token；八条全不同的题平均 323 个 token |
| 长输出的重复 | 超过 50 个 token 的输出里只有 3 对相同 |

旧的错误是一次调用返回八条相同的输出，与长度无关。这里重复集中在极短的输出上：T = 0.7 下，一个只有七八个 token 的答案被独立采样两次得到相同结果是正常的。所以这是模型只答不写造成的，不是采样没有独立。

**门槛的适用范围。** 80% 的门槛是我在 `a56115d6` 里为三个 MATH v2 修复端点写的，用来确认修复生效，不是所有采样端点的通用规则。其他采样端点的停止条件仍是 `8bbf06a7` 的原话：多数题八条完全相同才停下汇报。这里是 12/500。以后的 pass@8 端点同时记录两项即可：种子与序列号是否各不相同；八条全同的题数。

**评分后的用法。** 这个端点的 pass@1 / pass@8 同样带着 §2 说的只答不写的问题，不能当作 4B 在 GSM8K 上的训练前能力；发布时注明这一点。
