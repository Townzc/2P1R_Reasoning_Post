### 2.1 固定项（与 P009 S1 逐项一致，脚本自动比对）

- **任务、学生、训练配方、评测**：同 §1。
- **题目**：(400,·) 与 (3200,1) 复用 S1 的 n400 / n3200 题目 ID 与顺序，三个教师完全相同。
- **教师提示**：同一 chat 模板和系统提示。
- **教师采样**：T = 0.8，top-p = 0.95，最多 1024 个新 token。

### 2.2 可用解的定义

同时满足以下四条：

1. 以 EOS 正常结束；
2. 没有被截断；
3. 能取出最后一个 `\boxed{}`；
4. 被冻结评分器判对。

### 2.3 选解规则（冻结）

**K = 1 格**
- T1.5 直接复用 S1 现有答案。
- T7 / T72 取最多 4 次尝试中的第一条可用解，并按教师分别报告重试比例。

**K = 4 / 8 格**
- 三个教师都对 400 题每题生成 16 次。
  - T1.5 的第 1 次尝试复用 P2 已有输出，2–16 次按同一 seed 规则补齐。
- 按尝试顺序，取前 K 条"可用且与已选解不重复"的解。
  - 去重：题内规范化文本精确去重，同 P008。
- 必须满足嵌套关系：K=1 ⊂ K=4 ⊂ K=8。
  - (400,1) 那条解必须是 (400,4) 的第一条。
  - T1.5 例外：S1 现有答案即第 1 次尝试，自然满足。

**凑不满 K**
- 保留该题实际的解数，不删题，也不拿别的题补。
- 报告实际 N 和凑不满的题数。
- **凑不满的题超过 10% 时：先汇报，再训练。**

**K = 1 格里 4 次都没对的题**
- 占比 ≤ 3%：用该教师第 1 次的输出（未验证），并报告数量。
- 占比 > 3%：先汇报，再训练。

### 2.4 覆盖检查（训练前）

- 用学生分词器计算 (3200,1) 和 (400,8) 各格的总监督 token（含 EOS）。所有格都必须 ≤ 2,097,148，且每条答案至少训练一次。
- **不满足：先汇报，不自动处理。**
  - 预案：受影响的整组对比，包括 T1.5 两个基线格，全部改为 2,048 步 / 4,194,296 token。
  - 这会改变训练量，需要负责人批准。

### 2.5 评测

- **主指标**：MATH-500 greedy（同 §1）。
- **次指标**：4 次采样的平均 pass@1。
  - 设置：T = 0.6，top-p = 0.95，seed 0–3，max 1024。
  - 对象：所有新训练的学生，加上 S1 的两个已有学生；后者只做新增采样评测，不重训。
- **E4 例外**：GSM8K greedy，max 512，冻结的 `first_stop` 解析器。
- **保存**：原始 token ID 与停止元数据。
- **评分**：在 CPU 上离线完成。
- **统计**：题目层面配对 bootstrap，10,000 次。
  - 500 题、单种子时，95% CI 约 ±3.7 pp，3 pp 左右的效应只是勉强可见。

### 3.3 E2：token cue 基线（Tier 1 搜索；Tier 2 扩展）

方法依据 arXiv:2610.06851 附录 A，并遵守笔记 48 的边界。

- **开发题**：按 hash 选 30 道 MATH train 题，且不在 n3200 中、不在 E1d 中。
- **候选生成**：
  - 用 S1 的 0-shot 提示，在 base 上做 beam search（宽 20、深 2），得到 20 个开头；
  - 另加"无 cue"作为一个候选。
- **候选采样**：
  - 每个候选 × 每题采 16 次；
  - T = 0.6，top-p = 0.95，max 1024。论文用的是 16,384，需披露这一差异。
- **候选筛选**：
  - 去掉缺答案率比"无 cue"高 10 pp 以上的候选；
  - 在剩余候选中选平均答案熵最低的那个。
- **评测**：
  - Tier 1：base × {无 cue, cue}，在 MATH-500 与 GSM8K 上，用 greedy + 4 次采样。
  - Tier 2：{T1.5-n400 学生, T72-(400,1) 学生} × {无 cue, cue}，只测 MATH-500。
- **约束**：测试集不参与选 cue；整个选择过程全部落盘。

## 4. 预先冻结的判读（探索性）

**记号**

| 记号 | 定义 |
|---|---|
| Δ_P(t) | acc(3200,1) − acc(400,1) |
| Δ_K(t,K) | acc(400,K) − acc(400,1) |
| Δ_T | acc_T72 − acc_T1.5（同一格） |
| Δ_diag(t) | acc(400,8) − acc(3200,1) |
| Δ_diff | E1d − T72(3200,1) |

**"明显"**：差值 ≥ 3 pp，且 95% CI 下界 > 0。

| 结果 | 含义 | 报告后的主设定 |
|---|---|---|
| O1：Δ_P(T72) 明显 | 强教师下题数重新起作用 | T72（+T7）× MATH，做完整三轴，再做联合分配 |
| O2：Δ_T 明显，Δ_P 都平 | 杠杆是教师质量 | 联合分配以"教师 × P"为主，K 取小值 |
| O3：某教师的 Δ_K 明显 | 每题多解有价值 | 联合分配以 P × K 为主，温度作为一个因子 |
| O4：Δ_diff 明显 | 题目难度覆盖是瓶颈 | 改用不筛选的题目，加难度分层 |
| O5：主网格平，E4 或 E5 有斜率 | 瓶颈在学生 | 换学生后再做分配 |
| O6：全部 \|Δ\| < 2 pp | 该规模下数据分配不敏感 | 转向 OpenThoughts 长 CoT + 更大学生，或研究"激发的最低成本" |

- Δ_diag 不论正负都要报告。
- T72 < T7 时，记为可能的 learnability gap（Li et al. 2025），不视为异常。
