## A7-1 同源短解对照

### 设计

对每一份已冻结的 M512，让写长解的那位教师把自己的长解改写成简短版本，得到第三份训练文件 `concise.jsonl`。题目、顺序、标准答案与该 M512 的 `long.jsonl`、`short.jsonl` 完全相同。

| 训练解答 | 来源 | 长度 |
|---|---|---|
| `short.jsonl`（已有） | OMI-2 | 短 |
| `long.jsonl`（已有） | Qwen3.5 教师 | 长 |
| `concise.jsonl`（新增） | 同一位 Qwen3.5 教师 | 短（目标与 OMI-2 短解相当） |

- 同源短解 对 长解：来源相同，长度不同。
- 同源短解 对 OMI 短解：长度相近，来源不同。

### 构造规则（冻结）

| 项 | 规则 |
|---|---|
| 输入 | 9B 的 M512：`a6_2_9b_m512_v1/long.jsonl`（sha256 `2d597318…`）与 `short.jsonl`（`7f6dd97f…`）；4B 的 M512：`a6_2_4b_m512_and_cross_teacher_preparation_v1/long.jsonl`（`bf4dd2d4…`）与 `short.jsonl`（`55dc02f3…`） |
| 教师 | 9B 的 M512 用未微调的 Qwen3.5-9B；4B 的 M512 用未微调的 Qwen3.5-4B。渲染器 `qwen3_5_disable_thinking`，与 M512 构造时相同 |
| 提示词 | 单轮用户消息，模板见下，逐字使用；三个替换位用字面替换，不要用会解释花括号的格式化函数 |
| 目标词数 N | 同一题 OMI-2 短解按空白切分的词数，四舍五入到 10，最小 20 |
| 尝试 | 每题最多 4 次；第 1 次 greedy，第 2–4 次 T = 0.7、top_p = 1.0；`max_tokens` 2,048 |
| 种子 | `7000 + 行号 × 4 + 次数`，行号是该题在 M512 文件里的位置（从 1 起），次数从 1 起 |
| 合格 | 正常终止；含 `\boxed{}`；最后一个 `\boxed{}` 用现有评分器判为正确；不含思考标签或特殊符号 |
| 选取 | 取第一条合格的，去掉末尾的终止符 |
| 回退 | 4 次都不合格的题，这一行沿用原长解（保持来源纯净），并在清单里逐题列出 |
| 停止条件 | 回退行超过 26 行（5%）时，不训练，先报告 |
| 长度 | 不设逐题长度门槛；长度由下面的操纵检查在整体上判断 |

提示词模板（`{N}`、`{raw_problem}`、`{long_solution}` 为替换位）：

```
Below is a math problem and a correct solution. Rewrite the solution so that it is concise: keep only the essential steps, use about {N} words, and keep the same final answer inside \boxed{}. Output only the rewritten solution.

Problem:
{raw_problem}

Solution:
{long_solution}
```

构造完成后、训练之前，Codex 报告：两份 `concise.jsonl` 的哈希、回退行数、各学生 tokenizer 下的监督 token 统计，以及与同题集长解、OMI 短解的 token 数之比。

我的点估计：9B 同源短解约 77%（OMI 短 72.2%，长 91.1%）；4B 同源短解约 71%（65.4%，87.6%）。

**事先约定的解读。**

- 长解 − 同源短解 < 5pp：差别主要来自来源，不是长度。"长解答有效"这个说法不成立，应改为"解答由谁写"。
- 长解 − 同源短解 ≥ 10pp，且同源短解 − OMI 短解 < 5pp：差别主要来自长度（或细致程度）。
- 介于两者之间：两者都有贡献，按两段差值分别报告，不归因于单一因素。
- SC-3b 不成立（同源短解臂的输出并不短）：这一臂没有检验到长度，不用于上述判断。
- 同源短解与长解的推理路径相同、只是写得简略；它检验的是"同一来源下写得长短"，不检验"不同来源的长解"。后者仍然没有对照。
