# 主网格 K8 数据里，同一道题的 8 条解彼此差多大

- 日期：2026-11-23（PST）
- 性质：我自己的描述性统计，不在 Codex 的正式分析里，不改变任何判定。
- 数据：冻结的 C6 数据 `gsm8k/K8.jsonl` 与 `math/K8.jsonl`（各 512 题 × 8 条解，共 4,096 行）。本目录不含任何题目或解答文本。
- 方法：同一题的 8 条解两两比较，每题 28 对，每个任务 14,336 对。相似度是分词后序列的 `difflib.SequenceMatcher` 比值（0 为完全不同，1 为完全相同）。对照组是随机抽取的不同题目的两条解（4,000 对）。

| | GSM8K | MATH |
|---|---:|---:|
| 完全相同的解对 | 0 | 0 |
| 同题两条解的相似度，中位数 | 0.565 | 0.392 |
| 第 10 到第 90 百分位 | 0.36 到 0.76 | 0.19 到 0.63 |
| 对照：不同题目的两条解，中位数 | 0.149 | 0.115 |
| 相似度 ≥ 0.9 的解对 | 0.84% | 0.05% |
| 相似度 ≥ 0.8 的解对 | 5.45% | 0.76% |
| 至少含一对 ≥ 0.9 的题 | 14.1% | 1.4% |
| 出现的数字序列完全相同的解对 | 11.8% | 0.7% |
| 四元组 Jaccard，中位数 | 0.161 | 0.126 |
| 解的长度（分词数），中位数 | 110 | 225 |

读法：

- 没有重复的解；近似重复（≥ 0.9）在 GSM8K 上不到 1%，在 MATH 上几乎没有。「多解」格不是「重复」格的变体。
- 这是文字层面的差别，不等于解题思路不同。GSM8K 上约 12% 的解对用到的数字序列完全一样，即同一套计算、不同的表述。
- 解答来自 OpenMathInstruct-2，不是我们自己生成的；这里只说明进入训练的 8 条解彼此不同到什么程度。
