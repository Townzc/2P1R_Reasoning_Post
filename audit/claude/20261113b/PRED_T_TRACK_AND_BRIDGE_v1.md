## 1. 判定口径

- 指标：greedy 准确率。MATH 用完整测试集 5,000 题；与训练前基线比较时用 MATH-500 子集（基线只有这 500 题）。
- "明显"：|Δ| ≥ 3pp，且按题配对 bootstrap 的 95% 区间不含 0。seed 29 出来后再加"两个种子同方向"。
- 每条预测后面的百分数是我对它成立的把握。

## 2. T 轨 × MATH（Qwen3.5-4B、Qwen3.5-9B、Qwen3.5-9B-Base）

除注明外，每条对三个模型分别成立。

| 编号 | 预测 | 把握 |
|---|---|---:|
| T1 | 加数据不明显：\|P − L\| < 3pp | 80% |
| T2 | 重复受损：L − R ≥ 3pp，区间不含 0 | 65% |
| T2b | R 格学到了记忆：最后 32 步的平均训练 loss < 0.05 | 75% |
| T3 | 多解不明显：\|P − K8\| < 3pp | 80% |
| T4 | 五格里 R 最低 | 70% |
| T5 | 4B、9B：SFT 没有明显收益。P − max(0-shot 基线, 4-shot 基线) < +3pp（MATH-500） | 75% |
| T6 | 9B-Base：SFT 有明显收益。P − 4-shot 基线 ≥ +3pp（MATH-500） | 70% |
| T7 | T6 的差值大于 9B 在 T5 里的差值（base 的收益大于 Instruct） | 75% |
| T8 | 4B、9B 的 P 格截断率 < 5% | 70% |

**这些预测从哪里来。** 主网格的两个 Qwen × MATH 设定在 seed 17 下给出同一个模式：

- P 与 L 没有差别（base −0.8pp，Instruct +0.1pp）；
- R 比同样数据只训 2 轮的 L 低约 10pp，R 的训练 loss 降到 0；
- P 比 K8 高 1.9pp，不到 3pp。

T1–T4 就是假设这个模式在更大的模型和 LoRA 下仍然成立。T5–T7 来自 H1（Instruct 的 SFT 收益小于 base）。

**事先约定的解读。**

- T1–T4 都成立：在这个算力水平上，"只有重复会造成损害"这一模式不依赖模型规模和微调方法。
- T2b 成立而 T2 不成立：模型记住了重复的样本，但泛化没有明显受损。这说明容量更大的模型对重复更耐受，是一个新的边界条件。
- T2b 不成立：LoRA 在这个设置下没有记住 512 条样本，T2 没有被检验到，不能当作"重复无害"的证据。
- T1 不成立（P 明显高于 L）：更大的模型在这个预算下反而还没饱和，与主网格相反，需要回头检查学习率和步数是否可比。

## 3. T 轨 × GSM8K

| 编号 | 预测 | 把握 |
|---|---|---:|
| G1 | 4B、9B：P、K8、K4、L 两两之差都 < 3pp | 85% |
| G2 | 4B、9B：L − R < 3pp（重复的损害不明显） | 60% |
| G3 | 4B、9B：P − max(0-shot, 4-shot) < +3pp | 85% |

理由：这两个模型在 GSM8K 上预计接近上限，没有多少可以拉开的空间。

## 4. 桥接格（Qwen2.5-1.5B base × MATH，LoRA，seed 17）

| 编号 | 预测 | 把握 |
|---|---|---:|
| B1 | \|P − L\| < 3pp | 75% |
| B2 | L − R ≥ 3pp，区间不含 0 | 80% |
| B3 | \|P − K8\| < 3pp | 75% |
| B4 | 桥接格的 P 与全量微调的 P（42.06%）相差不到 5pp | 55% |

桥接格只有一个种子，"明显"只按幅度和区间判断。
