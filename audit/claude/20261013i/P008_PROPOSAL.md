## 0. 诊断：为什么 P007B 是 null

1. **处在"数据量不敏感区"。** P007B 四格的可用答案数从 91 到 474，相差 5 倍，但两 seed 平均准确率只从 71.1% 变到 72.8%（按可用数排序：91→71.1%，230→72.1%，408→72.8%，474→72.3%；这只是描述，混有题价和曝光的影响）。大约每翻一倍数据才 +0.8pp。在这个区间，学生的提升主要来自学会格式（与 URIAL 和 superficial alignment 的观察一致），数据怎么分配几乎不重要。
2. **动态范围窄。** Qwen2.5-1.5B base 的 GSM8K 4-shot 约为 68.5%，教师 Qwen2.5-Math-1.5B-Instruct 约为 84.8%（两者都是技术报告数字，需要 Codex 用我们自己的评测核实 base），学生约 72%。所以 1× 预算下，策略差异的上限本来就很小。
3. **噪声与效应同一量级。** 从 8 个模型估计，单格的训练 seed SD 约 0.65pp，策略差值约 0.9pp，交互项约 1.3pp；题目层面的 SE 约 1.1pp。
4. **文献预测效应会随预算变大**（预测方向在看结果之前就写进预注册）：*When Does Generating More Help?*（小预算时两种方向接近，预算变大后扩充题目更强）；OpenMathInstruct-2 Fig. 6（256K 对固定时，题目越多越好）；RFT（笔记 31：更多不同的推理路径有收益）。

**结论：** 继续在 1× 加 seed，是在效应约等于 0 的点上做重复。应该把实验放到理论预测效应更大的区间。

## 1. 关键方法杠杆：共同随机数教师池（common random numbers pool）

题价是假设计价（hypothetical tariff），所以"采购"可以完全离线重放：

- 对 GSM8K train 全部 7,473 题，每题生成 K=8 次教师回答。prompt、SAMPLING（T=0.8，top_p=0.95，max 1024）、EOS 和 usable 检查器都与 P007B 相同。每次采样的随机种子 = hash(problem_id, attempt)。
- 所有"策略 × 题价 × 预算"都用冻结的 `Policy` 和 token 计价，从同一个池中按需取用，也就是 P007B 已有的 replay 机制。不同策略在同一题、同一次尝试上看到的是**同一份**教师输出，这样策略差值中的采购噪声大幅下降（正是 Codex 下一阶段方案中第 1 条"预定义 (problem, attempt) 随机流"）。
- 生成用 vLLM（per-request seed），1.5B 教师约 6 万次生成、约 2,000 万 token，预计在 1 张 H100 上不到 30 分钟，约 $5–10。教师输出是**数据**，不是评测，所以换后端不会影响学生评测契约。备选：HF 加大 batch，多卡并行，约 $30。
- 池中未被任何策略用到的生成，计入真实平台费用，不计入策略的假设采购费用（与 Codex 方案一致）。
- 题目顺序用一个新的冻结排列（draw D1），因此 1× 也是一次**新的独立采购**（回应 S8-1）。

## 3. 预注册假设与分析（在任何 P008 学生结果出来之前冻结）

- **H1（预算效应）：** 对每个"策略 × 题价"，acc(16×) − acc(1×) > 0。
- **H2（核心）：** p0 下，depth − breadth 的差值随 log₂B 下降（扩题收益更大）；p4 下，差值不下降或上升。
- **H3：** 16× 时的题价交互 > 0，方向与 P007B seed17 的点估计相同。
- **分析：**
  - 每个 seed 和每个 draw 的结果都要逐个报告。
  - 主检验是"差值对 log₂B 的回归斜率"，用 1×、4×、16× 的全部运行（1× 包括 P007B 的 2 个 seed 和 D1，作为两个采购 draw）。这样能综合 3 个预算点的信息，比单点比较更有功效。
  - 题目 bootstrap 和 seed 层面的离散度分开报告，不把题目区间说成 seed 区间。
  - 次要指标：等准确率成本比（iso-accuracy cost ratio）。准确率大致随 log 预算增长，所以 1.5pp 的差距约等于 2 倍以上的成本差。这个比值可以讲，但必须带区间。
- **功效（据实）：** 我的粗估是，H1 出现清楚效应（16× 比 1× 高 ≥ 2pp）的概率约 70%；H3 区间不含 0 的概率约 30–40%。如果 H2/H3 仍然是 null，因为跨了 3 个预算点，区间会更窄，结论变成"在 1×–16× 范围内，分配差异 < X pp"，再加上预算曲线，这比现在的单点 null 扎实得多。

## 8. 关于"发布要 SOTA 或突出表现"（坦率意见）

1.5B 学生做数据分配研究，以 GSM8K 绝对分数的 SOTA 为目标既不现实，也不是这类论文的评判标准。ICML/ACL 这类工作的"突出表现"通常是：

1. **一个经过验证的分配规律或决策规则：** 给定预算 B 和题价 p，预测最优的 P/R，并在没有用于拟合的新预算、新任务上验证。
2. **同等教师成本下明显胜过标准做法：** 例如均匀 k 次拒绝采样（RFT、MetaMath 风格）、DART-Math 的难度感知采样，以"同等准确率下成本低 2–4 倍"的形式呈现。
3. **跨至少 2 个任务（GSM8K + MATH）和至少 2 组学生/教师。**

P008 的预算阶梯是第 1 点的地基。中期后，用 $2,700 做难度或学生感知的自适应采购（第 2 点，最可能拿到大效应），再在 MATH 上复现（第 3 点）。评测改用 vLLM（R13-1）可以让每个学生的成本降到原来的一小部分，这是能负担这些实验规模的前提。
