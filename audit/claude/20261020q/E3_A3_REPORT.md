## 备注

1. **关于"序列化差异"**：Codex 指出，我 20261020o 附带的 `A1_E3_RESULT.json` 里记的是 1510，报告正文写的是 1600。原因是脚本里 digest 用了 `ensure_ascii=False`，与 Codex 的 canonical 定义（ASCII 转义）不一致。改用 ASCII 转义重算后是 1600/1600，报告正文给的就是这个数，但附带的 JSON 没有同步更新。**这是我的疏漏**。原文件保持不动，在此说明：数据本身没有问题。
2. **表达式 Jaccard 的口径**：它是词面的数学表达式集合重叠，包含单个符号；两边都为空时记为 1。T1.0 的"全部 28 对"里有 2 对两边都为空。
3. **共同随机数**：三档温度共用 seed，所以同一槽位在不同温度下的开头常常相同，样例为 algebra/791 的 attempt01。温度之间的差异应理解为**同一随机流下的配对比较**，不是独立样本。
4. **描述性数据**：本节没有置信区间，也没有"哪档温度更好"的结论；这些由负责人判断和撰写。
5. **审计局限**：我没有运行 vLLM 或 math-verify。评分正确性的证据是：box 抽取一致、字符串检查、21 种符号等价逐一人工核对，以及评分器 SHA 未变。
