## C. 我认为 Codex 的 11 项方案过于保守的地方

1. **它回答不了它自己提出的核心问题。** Codex 写的"真正有价值的问题"是"分配偏好如何随 B、T、p 共同变化"。但它的 8 个主运行都在 4× 这一个预算上，P008 协议内唯一的跨 B 信息，是 breadth-p0 一格的桥接，而且没有对应的 depth。所以"偏好随 B 怎么变"只能拿 P007B 的 1×（HF、不同协议）来和 P008 的 4× 比，而这正是 Codex 自己在 V2-3 中判定不可比的做法。**要回答这个问题，P008 协议内部至少需要 2 个预算档，且两种策略都要有。**
2. **只在 4× 做，有再得到一次 null 的风险。** 文献给出的动机是"预算越大差异越明显"，4× 仍可能处在差异很小的区域。选 8×：breadth p0 大约用掉题池的 48%，不会把题池用尽。
3. **规模。** 11 项学生训练只用了原方案约 23% 的训练量。owner 已在对话中批准这 20 小时内 $250；当前平台计量约 $87，加上 $250 也在原来 $450 的支出上限之内。owner 应直接向 Codex 确认这笔经费（按 owner-sends 规则）。
4. **周三。** owner 明确说过："周三我排练，然后你们继续工作，如果有重大更新就调整 ppt"。Codex 主张周三只修错误，比 owner 的安排更严。我的折中：周二 21:00 冻结的结论是中期的主体，不再改动；周三的新结果只有在周三 18:00 前通过我的审计，才能以单独标注"探索性更新"的形式加进去，而且不改写已冻结的结论。

## D. v3 合成方案（供讨论，未准入）

**Phase 0：工程测量（约 2 小时，≤ $15，门 G0 只看工程指标）**

- 在 256 道固定题上，用 vLLM 生成教师回答（draw 专属种子），测吞吐和输出长度分布，并与 P007A 的 HF 可用率（959/1024 = 93.7%）比较分布是否一致（报告结果，不做筛选）。
- 测 4× 和 8× 训练剂量的训练时间、HF 评测时间，以及 4 卡并发能否正常运行。
- 从 GSM8K train 中用固定种子留出 500 题作为未来的开发集，不进入教师池。

**主设计**

| 部分 | 内容 | 运行数 | 训练量（P007B 单位） |
| --- | --- | ---: | ---: |
| 主比较 | 2 个独立 draw × B∈{1×, 8×} × p∈{0, 4m} × {breadth, depth}，每个 draw 用 1 个训练 seed；T = 524,287 × B（联合路径） | 16 | 8 + 64 = 72 |
| B×T 桥接 | D1、p0、两种策略都做，补齐 2×2 的另外两角：(8×B, T0) 和 (1×B, 8T0)，与主比较中已有的 (1×, T0)、(8×, 8T0) 组成完整的 2×2 | 4 | 2 + 16 = 18 |
| base | 与主评测完全相同的契约 | 1 | — |
| **合计** | | **20 个学生 + base** | **90**（v2 为 164，Codex 方案为 38） |

**教师供给：** 每个 draw 只生成策略需要的候选并集（按需前缀），约 1.4 万次生成，不预先生成 7,473 × 8。池用尽与缺额如实记录。

**粗估：** 训练约 10.6 GPU 小时，其他 worker 时间约 22 GPU 小时，约 $145；加上教师生成、base 和 CPU 审计约 $175（Phase 0 实测后修正）。4 卡并发时墙钟时间约 8–9 小时。

**派发顺序**（保护最重要的对比；不设效果门）：第 1 波 D1 主 8 格 + base → 第 2 波 D2 主 8 格 → 第 3 波桥接 4 格。

**预先写好的备选方案（只由 Phase 0 的测量触发，在任何学生结果之前决定）：**

1. 预计总费用 > $200，或预计完成时间晚于 18:00 → 砍掉 (1×B, 8T0) 两格。
2. 仍然超出 → 主比较和桥接的 8× 一律改为 4×。
3. 仍然超出 → 砍掉 D2，此时明确不作采购复现的主张。

**预注册：**

- 每个 draw 内：Δ_p(B) = acc(depth) − acc(breadth)；变化量 C_p = Δ_p(8×) − Δ_p(1×)；交互 I(B) = Δ_4m(B) − Δ_0(B)。
- 方向性先验（来自文献，写在结果之前）：C_0 < 0，即预算变大时扩题受益更多。p4 不设方向先验。
- 每个 draw 单独报告，再报告两个 draw 的均值和极差；题目 bootstrap 是条件区间。两个 draw 不支持总体区间。整体定位为探索性估计，不作确认性检验。
- 桥接用于分解：在 p0 锚点上，策略差异的变化来自数据（B）还是训练（T）。

**情景式最小可检测效应（示意，不是功效承诺）。** 假设如下：两个 draw 独立；单个 draw 内一个对比的题目层面 SE 约 1.1pp（已实测）；draw 层面的 SD 为 s；正态近似，80% 功效，双侧 5%。

| s（draw 层面 SD） | 两个 draw 均值下 C_0 的 MDE |
| --- | ---: |
| 0.9pp（只有训练噪声，即 P007B 的估计） | 约 4.0pp |
| 2pp | 约 6.4pp |
| 3pp | 约 9.0pp |

结论（据实）：20 小时内，任何设计都只能检测到大的效应（≥ 4pp）。选 8× 的理由，是让真实的大效应有机会出现，而不是保证显著。
