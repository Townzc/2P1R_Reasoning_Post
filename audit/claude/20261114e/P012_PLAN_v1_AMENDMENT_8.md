## 2. 规律

对每个"模型 × 任务"设定，格子记为 (P 题数, K 每题解数, E 轮数)：

```
acc(P, K, E) = a + b·log2(P / 512) + c·log2(K) + s·log2(E / 2)
```

四个参数由已有四格的两个种子均值直接给出，没有自由度：

| 参数 | 取值 | 含义 |
|---|---|---|
| a | L | (512, 1, 2) 的准确率 |
| b | (P − L) / 3 | 题数每翻一倍 |
| c | (K8 − L) / 3 | 每题解数每翻一倍 |
| s | (R − L) / 3 | 轮数每翻一倍 |

同算力下"新解"相对"新题"的兑换率是 β = (c − s) / (b − s)，等于 (K8 − R) / (P − R)。

**事后已看到的支持与反例**（不算验证）：

| 设定 | β [95% 区间] |
|---|---|
| Llama base × GSM8K | 0.64 [0.54, 0.74] |
| Llama Instruct × GSM8K | 0.56 [0.45, 0.69] |
| Qwen base × GSM8K | 0.60 [0.42, 0.79] |
| Qwen Instruct × GSM8K | 0.68 [0.52, 0.83] |
| Llama Instruct × MATH | 0.73 [0.64, 0.82] |
| Qwen base × MATH | 0.83 [0.74, 0.93] |
| Qwen Instruct × MATH | 0.88 [0.79, 0.98] |
| Qwen3.5-4B × MATH（Tinker，LoRA） | 0.88 [0.82, 0.95] |

- K4（没有参与拟合）：9 个设定里 7 个的残差区间含 0；Llama Instruct × GSM8K 偏差约 +3pp，4B × MATH 偏差约 +1pp。
- 4B × MATH 的 E4、E8：残差 −0.6、−1.0pp。9B 与 Qwen2.5-1.5B 的 E4 残差约 −2pp。
- **反例**：向极小预算外推不成立。4B 的 L64（64 题，16 步）预测 71.5%，实测 66.9%。训练前后的落差发生在最初十几步，不是对数线性的。因此本规律只对"已经训练过一定步数"的范围提出，新格子都在 256 步以上。

两条事先固定的对照规则，参数同样只来自已有格子：

| 规则 | 设定 | 含义 |
|---|---|---|
| β = 1 | c 取 b | 只有不同样本的总数重要，新解等于新题 |
| β = 0 | c 取 s | 只有不同题目的数量重要，新解等于重复 |

## 4. 数据与训练

- **数据**：沿用 C6 的嵌套规则。(P, K) 取 `training4096` 顺序的前 P 题、每题按既定顺序的前 K 条解。新文件必须与已有的 L、K4、K8、P 嵌套一致。
- **训练**：与主网格逐项相同（全量微调，LR 1e-5，按本格步数做 cosine，batch 8，seed 17）；步数 = P × K × E / 8。T 组与 Tinker 线相同（LoRA rank 32，原学习率）。
- **评测**：与主网格相同。GSM8K 1,319 题，MATH 5,000 题，greedy。
- **审查**：如果数据构建和启动只是换参数、源码哈希不变，不需要预审；我事后对所有新数据文件核对嵌套和条数，并全量重评结果。如果需要改源码，先把 diff 发我。

## 5. 判定标准（冻结）

残差 r = 实测 − 预测。

| 项 | 标准 |
|---|---|
| 单格命中 | GSM8K：\|r\| ≤ 4pp；MATH：\|r\| ≤ 2.5pp |
| 一组"成立" | 命中率 ≥ 80%，且平均残差在 ±1.5pp 以内 |
| 一组"部分成立" | 命中率 ≥ 60% |
| 一组"不成立" | 其余情况 |
| 与对照规则比较 | 在 K > 1 的新格子上，比较三条规则的 RMSE |
| 可分性 | A 组用 (4096, 1, 2)、(4096, 2, 2)、(4096, 4, 2)、(4096, 8, 2) 重新估计 c，与 3.05 相差不超过 1pp / 翻倍 |

- 命中阈值偏宽：GSM8K 只有 1,319 题，预测的 SE、新格子的抽样误差和种子波动合起来约 2.2pp。B、C 两组的预测范围窄，主要看与对照规则的比较，不单看命中率。
- 另按两个子集分别报告：只含 E = 2 的格子；含 E ≠ 2 的格子。
- 无论结果如何，26 个格子全部报告，不事后剔除。
