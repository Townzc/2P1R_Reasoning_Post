## 2. A4-2 Tinker 轨（T 轨）：同一设计的 LoRA 复制

取代计划 v1 的 E4，范围扩大。

**目的。** 在另一组模型上原样重复主网格的 5 格设计，检验主网格得到的规律能否预测新设定的结果（先预测、后验证）。T 轨不是主结果，也不与主网格合并统计。

**模型。**

| 模型 | 作用 |
|---|---|
| Qwen/Qwen3.5-4B | 同一代内的小模型 |
| Qwen/Qwen3.5-9B | 同一代内的大模型；与 4B 构成只改变规模的对比 |
| Qwen/Qwen3.5-9B-Base | 与 9B 构成只改变 base / Instruct 的对比 |

三个模型同代、同方法（LoRA）、同数据，所以 T 轨内部的每个对比只改变一个因素。

**设计（与主网格逐项相同的部分）。**

- 数据：直接使用 C6 冻结文件（`P`、`K8`、`K4`、`R`、`L`），先核对 sha256；训练输入仍是 OMI-2 提示词包裹后的 `problem`。
- 剂量：batch 8；P、K8、K4、R 各 1,024 次更新，L 为 128 次；轮数与主网格相同（R 为 16 轮）。
- 调度：cosine 衰减到 0，无 warmup，weight decay 0，Adam (0.9, 0.999, 1e-8)。
- 种子：17（5 格），29（P、K8、R、L）。同一种子下的数据顺序规则与主网格一致。

**只能不同的部分（预先固定，不按格调参）。**

- LoRA rank 32（Tinker 默认）。
- 学习率：`tinker_cookbook.hyperparam_utils.get_lr(model, is_lora=True)` 的返回值，每个模型一个值，五格共用；把实际数值写进 manifest。不做学习率搜索。
- 渲染（renderer）：三个模型都用 `qwen3_5_disable_thinking`，训练和评测一致。理由：训练解答是不带 `<think>` 的普通 CoT 文本。9B-Base 用同一个渲染器，这样它与 9B 的差别只在初始化。Codex 需确认 Base 的 tokenizer 含同样的特殊 token，并核对渲染结果与 HF `apply_chat_template(enable_thinking=False)` 一致。
- 损失只算 assistant 段（含结束符 `<|im_end|>`）。

**评测。**

- 提示词、解码、评分与主网格相同：OMI-2 提示词，greedy（temperature 0），`max_tokens` 4,096，停止符取渲染器的 stop sequences，评分用现有 `scoring.py`。
- 测试集：完整 MATH 5,000 题（同时报 MATH-500 子集）、GSM8K 1,319 题。
- 每格必报：准确率、截断率、循环数、"正常终止题目"上的准确率（与 A3-3 相同）。
- 训练前测量（与 C7 对应）：4-shot 基线（主基线）、0-shot（仅 4B 和 9B）、留出 500 题的 pass@1 / pass@8、教师解 NLL（每 token 和每字符；用不更新权重的前向计算）。
- 保存全部原始输出和 token 用量。

**顺序与预算。**

| 步骤 | 内容 | 预测 | 上限 |
|---|---|---:|---:|
| T-smoke | 每个模型：渲染样例、L 格前 20 步、20 道题评测。只为审查包提供真实输出，不算结果 | $2–5 | $5 |
| T-MATH | 3 个模型 × MATH：训练前测量 + seed 17 五格 + seed 29 四格 | $154–206（另加训练前 pass@8 与 NLL 约 $10） | $230 |
| T-GSM | 3 个模型 × GSM8K：同上 | $75–91（另加约 $6） | $105 |
| **合计** | | | **$340** |

- 单价取自 Tinker 定价页（2026-10-19 版）：Qwen3.5-4B 训练 $0.737、采样 $1.005；Qwen3.5-9B 与 9B-Base 训练 $1.463、采样 $0.807（每百万 token）。
- 用量假设：MATH 每条训练样本约 420 token，GSM8K 约 300；评测输出按"正常终止"到"10% 截断"两种情形给出区间（后者取自主网格 L 格实测的 3.52M token / 5,000 题）。
- 先做 T-MATH，再做 T-GSM。GSM8K 对这三个模型大概率接近满分，信息量低，时间不够就砍掉。
- 各格互不依赖，并行提交。
- 余下的 Tinker 额度（不少于 $400）留给汇报之后的工作。

**流程。**

1. Tinker 的训练和采样是新代码路径，首次正式运行前送审一次（连同 §3 的桥接格）。T-smoke 可以在送审前跑。
